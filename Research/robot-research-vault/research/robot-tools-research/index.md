## Проходы исследования

### Проход 1 — NVIDIA инструменты (2026-04-08)

**Цель:** найти бесплатные NVIDIA инструменты с профитом для проекта.

**Результаты:**
- Isaac Sim 5.0 — ❌ официально ниже минимума (требует RTX 3070+ / 16GB VRAM)
- Isaac Lab — ❌ строится на Isaac Sim, то же ограничение
- GR00T — ❌ inference минимум RTX 3090, fine-tuning RTX 4090/A6000
- Ollama + Phi-3 / Llama 3.2 — ✅ уже в стеке, работает

**Вывод:** NVIDIA экосистема на текущем железе недоступна. Закрыто.

### Проход 2 — Unitree + мастодонты (2026-04-08)

**Цель:** изучить что открыл Unitree и другие крупные игроки.

**Результаты:**
- MuJoCo Playground (DeepMind) — ✅ GPU RL через JAX, работает на RTX 3050
- unitree_rl_mjlab — ✅ готовый humanoid RL стек на MuJoCo, Apache 2.0
- Newton (NVIDIA+DeepMind+Disney, Linux Foundation) — beta, следить

**Вывод:** MuJoCo Playground + unitree_rl_mjlab — приоритет для Phase 2.

## Аргументы за MuJoCo Playground

1. **Работает на нашем железе** — JAX на RTX 3050 6GB, нет ограничений
2. **Обучение ходьбе за минуты** — на одном GPU
3. **Apache 2.0** — нет ограничений на использование
4. **Стандарт индустрии** — DeepMind, OpenAI, Stanford, ETH Zurich
5. **Python-first** — тот же язык что весь наш стек
6. **Готовые humanoid окружения** — не писать физику с нуля
7. **sim2real pipeline** — обучить политику → запустить на RPi через Zenoh

## Аргументы за unitree_rl_mjlab

1. **Готовый URDF гуманоида G1** — production-качества, эталон для нашего URDF
2. **Готовые reward функции для ходьбы** — не изобретать велосипед
3. **Тот же стек (MuJoCo)** — адаптация под наш URDF минимальна
4. **Активно поддерживается** — Unitree, 2025-2026

---

## Как встраивается в стек

```
MuJoCo Playground ──обучение──► policy weights
        ↓
Webots (визуализация) ──Zenoh──► raspi_controller ──► реальные сервы
```

MuJoCo не заменяет Webots — параллельный инструмент для обучения политик.
Webots остаётся для hardware-in-the-loop (EXP-006).

## Текущее состояние URDF и симуляции

### Статус: ❌ Неудовлетворительно — блокер для RL обучения

`humanoid_v1.urdf` и `RoboforgeHumanoid.proto` созданы через генерацию
и содержат серьёзные дефекты.

### Дефекты URDF

| # | Дефект | Последствие |
|---|--------|-------------|
| 1 | Только примитивы (box/cylinder), нет mesh | Нет реальной геометрии, sim≠real |
| 2 | Нет `<collision>` у `left_hip` и `right_hip` | Бёдра проходят сквозь объекты |
| 3 | 15 DOF вместо заявленных 20 по HLD | Нет `hip_roll` — ходьба физически некорректна |
| 4 | Нет `shoulder_roll` | Руки двигаются только в одной плоскости |
| 5 | `shoulder_pitch` с нестандартным `rpy="-1.5708"` в origin | Ломает IK |
| 6 | Inertia — placeholder значения | Физика нереалистична |

### Дефекты PROTO

| # | Дефект |
|---|--------|
| 1 | Автогенерирован `urdf2webots` — наследует все дефекты URDF |
| 2 | Нет поля `supervisor` — нужно ставить вручную |
| 3 | Визуально — набор коробок и цилиндров |

### Что нужно исправить (Q-24 — блокер)
