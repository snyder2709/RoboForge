# Сравнение протоколов коммуникации

Сравнительный анализ протоколов для выбора оптимального решения в распределённой робототехнической системе.

## Таблица сравнения

| Протокол | Latency     | Масштабируемость | Применение                    |
| -------- | ----------- | ---------------- | ----------------------------- |
| UDP      | минимальная | низкая           | управление в реальном времени |
| DDS      | низкая      | средняя          | робототехника (ROS2)          |
| MQTT     | средняя     | высокая          | IoT                           |
| Zenoh    | низкая      | очень высокая    | распределённая робототехника  |

## Выводы

- **UDP** — для критичных по времени команд управления движением
- **Zenoh** — для сервисного уровня и маршрутизации между узлами
