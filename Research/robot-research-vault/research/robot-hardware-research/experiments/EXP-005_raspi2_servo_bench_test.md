# EXP-005 — Стендовый тест сервоприводов на Raspberry Pi 2 Model B+

## Статус
🟡 Запланирован

## Цель

Проверить работу позиционных сервоприводов (SG92R и MG996R) через PCA9685 на
Raspberry Pi 2 B+ до закупки полного комплекта. Первый опыт работы с железом.
Питание от розетки, без Wi-Fi и Zenoh.

> **Важно:** использовать только позиционные серво (180°). SG90/SG92R с пометкой
> "360 degree" или "continuous rotation" — непрерывное вращение, не держат угол,
> не подходят для суставов робота.

## Почему SG92R вместо MG90S

| | MG90S | SG92R |
|---|---|---|
| Тип | Аналоговый | Цифровой |

| Шестерни | Металл | Карбон |
| Совместимость | — | Полная (тот же размер) |

| | GDW DS041MG | MG996R |

## Схема подключения

```
Raspberry Pi 2 B+          PCA9685
─────────────────          ───────────────────────
Pin 1  (3.3V)    ────────→ VCC  (логика 3.3V)
Pin 6  (GND)     ────────→ GND
Pin 3  (SDA, GPIO2) ─────→ SDA
Pin 5  (SCL, GPIO3) ─────→ SCL

БП 5V 3A (внешний)
(+) ────────────────────→ V+   (питание серво)
(-) ────────────────────→ GND

PCA9685 выходы            Сервы
──────────────────────────────
CH0 ──────────────────→ Серво 1 (SG92R — плечо)
CH1 ──────────────────→ Серво 2 (SG92R — локоть)
CH2 ──────────────────→ Серво 3 (MG996R — бедро)
```

## Программная часть

**ОС:** Raspberry Pi OS Lite (64-bit)

**Установка зависимостей:**
```bash
sudo apt update
sudo apt install -y python3-pip i2c-tools
sudo pip3 install adafruit-circuitpython-pca9685 adafruit-circuitpython-motor

# Включить I2C
sudo raspi-config  # → Interface Options → I2C → Enable

# Проверить что PCA9685 найден (должен показать 0x40)
sudo i2cdetect -y 1
```

**Тест скрипт:**
```python
import time
import board
import busio
from adafruit_pca9685 import PCA9685
from adafruit_motor import servo

i2c = busio.I2C(board.SCL, board.SDA)
pca = PCA9685(i2c)
pca.frequency = 50  # 50 Гц для серво

servo0 = servo.Servo(pca.channels[0], min_pulse=500, max_pulse=2500)

# Тест движения
for angle in [0, 45, 90, 135, 180, 90]:
    servo0.angle = angle
    print(f"angle: {angle}")
    time.sleep(1)

pca.deinit()
```

## Проверяемые гипотезы

- [ ] PCA9685 обнаруживается по I2C на адресе 0x40
- [ ] SG92R плавно двигается в диапазоне 0–180°
- [ ] MG996R держит позицию под нагрузкой
- [ ] Нет помех/перезагрузок Pi при движении серво
- [ ] Pulse width: min=500µs, max=2500µs (подобрать под каждый тип)
