# Архитектурные решения — Hardware

Зафиксированные решения с обоснованием (Architecture Decision Records).

## Решения

### ADR-001: Контроллер Phase 1–2 — ESP32 → RP2350 Pico 2W

**Статус:** Предложено (требует валидации)
**Дата:** 2026-03-16

**Контекст:**
HLD Hardware v1.1 использует ESP32 DevKit как основной контроллер робота.
В ходе исследования рассмотрены альтернативы с фокусом на энергоэффективность.

**Решение:**
Для Phase 2 (реальный робот) рассмотреть переход с ESP32 на RP2350 Pico 2W.

**Обоснование:**
- Потребление 20 mA vs 160 mA у ESP32 — 8× экономия при активной работе
- Размер меньше (51×21 mm vs 55×28 mm)
- zenoh-pico официально поддерживает RP2350 с января 2025
- Та же цена (~$5–7)
- Полная совместимость с текущей схемой (I2C, SPI, Wi-Fi, 3.3V)

**Риски:**
- cyw43 Wi-Fi библиотека в Rust менее зрелая чем ESP-IDF Wi-Fi
- Экосистема RP2350 моложе ESP32

**Последствия:**
- Phase 1 (Webots) — оставить ESP32, не менять железо на этапе ПО
- Phase 2 — заменить ESP32 на Pico 2W, обновить HLD Hardware до v1.2
- zenoh-pico код остаётся совместимым (C/FreeRTOS)

### ADR-002: Целевая платформа Phase 3 / v2.5 — SG2002

**Статус:** На заметку (не приоритет сейчас)
**Дата:** 2026-03-16

**Контекст:**
HLD Hardware v1.1 упоминает "v2.5 — MaixCAM как автономный мозг".
В ходе исследования обнаружен Sophgo SG2002 (Milk-V Duo 256M) — более мощная альтернатива.

**Решение:**
Зафиксировать SG2002 как целевую платформу для версии "автономный мозг" вместо MaixCAM.

**Обоснование:**
- Brain PC + контроллер + AI inference в одном чипе за ~$10
- RISC-V 700 MHz ядро под FreeRTOS → RT серво-контроль
- RISC-V/ARM 1 GHz ядро под Linux → полный Zenoh (Rust), координация
- NPU 1 TOPS → локальный AI inference без Brain PC
- 256 MB SiP RAM, WiFi 6, BT 5
- Убирает необходимость в отдельном Brain PC для автономного робота

**Риски:**
- Молодая экосистема (2024–2025)
- Нет проверенных примеров использования в роботике нашего масштаба
- Требует валидации latency FreeRTOS-ядра для 50 Гц серво-петли

**Последствия:**
- Обновить HLD Hardware v2.5: заменить MaixCAM на SG2002
- Провести эксперимент: серво-контроль через FreeRTOS на 700 MHz ядре
