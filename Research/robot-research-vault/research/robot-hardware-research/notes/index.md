# Заметки — Hardware исследование

Рабочие записи, наблюдения и находки по исследованию hardware решений.

## 2026-03-16 — Исследование контроллеров

### ESP32 → C/ESP-IDF (текущий HLD)

Принятое решение: MicroPython отброшен из-за GC-пауз 10–50 мс → jitter серво.
zenoh-pico — нативная C-библиотека, MicroPython-биндинга нет и не планируется.
Итог: C/ESP-IDF + FreeRTOS + zenoh-pico. Скелет ESP32 — 50% готовности, код не написан.

### Rust на ESP32

Rust на ESP32 через esp-rs возможен, но zenoh-pico всё равно C → нужен FFI.
Выигрыша нет: сложнее, а транспорт всё равно C. Rust имеет смысл на Brain PC стороне.

### Raspberry Pi Pico 2W (RP2350) — кандидат на замену ESP32

**Почему интересен:**
- Потребление активное: ~20 mA vs 160 mA у ESP32 — **8× экономия энергии**
- Размер: 51×21 mm — компактнее ESP32 DevKit (55×28 mm), вписывается в корпус
- zenoh-pico: официальная поддержка с января 2025
- Rust: rp235x-hal — значительно чище чем esp-rs
- Цена: $5–7

**Архитектура RP2350:**
- 2× ARM Cortex-M33 + 2× RISC-V Hazard3 @ 150 MHz
- 520 KB SRAM
- 3× PIO с 12 state machines — гибкое управление периферией
- Deep sleep: ~10 µA

**Совместимость с текущей схемой:**
- I2C → 2× PCA9685 + MPU-6050 ✓
- SPI → OV2640 камера ✓
- Wi-Fi → CYW43439 ✓ (библиотека cyw43 в Rust ещё не зрелая)
- 3.3V логика ✓

**Риск:** Wi-Fi библиотека cyw43 в Rust менее зрелая чем ESP-IDF Wi-Fi.

**Вывод:** Сильный апгрейд ESP32 при той же цене и том же zenoh-pico стеке.
Рекомендуется для Phase 2 как замена ESP32.

### STM32 — золотой стандарт реального времени

Детерминированный аппаратный PWM, отличный Rust через stm32-hal.
Но: дороже, сложнее в разработке. Избыточен для текущего масштаба.
На заметку для будущих версий с высокими требованиями к RT.

### Sophgo SG2002 / Milk-V Duo 256M — самая интересная находка

**Что это:** Гибридный SoC за ~$10 с несколькими архитектурами на одном чипе.

| Ядро | Частота | Роль |
|------|---------|------|
| RISC-V C906 | 1 GHz | Linux — Zenoh, координация |
| RISC-V C906 | 700 MHz | FreeRTOS — RT серво-контроль |
| MCU 8051 | 300 MHz | Периферия, сенсоры |
| NPU | 1 TOPS | Локальный AI inference |

- 256 MB SiP RAM на чипе
- WiFi 6 + Bluetooth 5
- Linux + FreeRTOS одновременно
- Полный Zenoh (Rust) на Linux-ядре

**Значение для проекта:** Brain PC + контроллер + AI в одном чипе размером с монету.
Потенциально убирает необходимость в отдельном Brain PC для автономного робота.

**Статус:** На заметку как целевая платформа для HLD v2.5 "автономный мозг".
Текущий приоритет — Phase 0–2 на ESP32/Pico 2W.

### RISC-V тренд 2025

RISC-V занял ~25% рынка embedded в 2025, рост 37% CAGR до 2030.
Открытая архитектура, нет роялти, кастомизация под задачу.
Для роботики: появляются специализированные чипы под управление суставами.
