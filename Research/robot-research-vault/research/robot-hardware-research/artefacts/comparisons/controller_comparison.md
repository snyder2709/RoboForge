# Сравнение контроллеров

Сравнение микроконтроллеров для модуля управления гуманоидного робота 28–30 см.
Требования: управление 20 серво через PCA9685, IMU, камера, Wi-Fi, zenoh-pico.

## Основная таблица

| Параметр | ESP32 DevKit | RP2350 Pico 2W | STM32F4 | SG2002 (Milk-V Duo) |
|----------|-------------|----------------|---------|---------------------|
| CPU | 2× LX6 240MHz | 2× M33 + 2× RISC-V 150MHz | Cortex-M4 168MHz | RISC-V 1GHz + ARM A53 + 700MHz RTOS |
| SRAM | 520 KB | 520 KB | 192 KB | 256 MB SiP |
| Потребление активное | ~160 mA | ~20 mA | ~30 mA | ~200–300 mA |
| Deep sleep | 5–20 µA | ~10 µA | <2 µA | — |
| Wi-Fi | Встроенный | CYW43439 | Нет (внешний) | WiFi 6 встроенный |
| zenoh-pico | Да (IDF component) | Да (с янв. 2025) | Да (FreeRTOS) | Полный Zenoh (Linux) |
| Rust | esp-rs (сложно) | rp235x-hal (хорошо) | stm32-hal (отлично) | Нативный Linux Rust |
| Real-time серво | FreeRTOS RT task | PIO + FreeRTOS | Аппаратный таймер (лучший) | FreeRTOS на 700MHz ядре |
| OS | FreeRTOS | FreeRTOS | FreeRTOS | Linux + FreeRTOS одновременно |
| NPU / AI | Нет | Нет | Нет | 1 TOPS NPU |
| Размер платы | 55×28 mm | 51×21 mm | Варьируется | ~43×26 mm (Duo 256M) |
| Цена | ~$5 | ~$7 | ~$10–20 | ~$10–15 |
| Зрелость экосистемы | Высокая | Средняя | Высокая | Низкая (новинка) |

## Энергоэффективность при работе от батареи 1200mAh

| Контроллер | Ток | Время работы (теория) |
|------------|-----|----------------------|
| ESP32 | 160 mA | ~7.5 ч |
| RP2350 Pico 2W | 20 mA | ~60 ч |
| STM32F4 | 30 mA | ~40 ч |
| SG2002 | ~250 mA | ~4.8 ч |

> Примечание: реальное время меньше из-за серво (~500–800 mA при движении).

## Совместимость с текущей схемой робота

| Интерфейс | ESP32 | Pico 2W | STM32 | SG2002 |
|-----------|-------|---------|-------|--------|
| I2C (PCA9685 ×2, IMU) | ✓ | ✓ | ✓ | ✓ |
| SPI (камера OV2640) | ✓ | ✓ | ✓ | ✓ |
| Wi-Fi | ✓ | ✓ | Внешний | ✓ |
| 3.3V логика | ✓ | ✓ | ✓ | ✓ |
| zenoh-pico | ✓ | ✓ | ✓ | — (полный Zenoh) |

## Рекомендации по фазам

| Фаза | Рекомендуемый контроллер | Обоснование |
|------|--------------------------|-------------|
| Phase 0 (виртуальный) | — | Симуляция, железо не нужно |
| Phase 1 (Webots) | ESP32 (текущий HLD) | Не менять, фокус на ПО |
| Phase 2 (реальный робот) | **RP2350 Pico 2W** | 8× экономия энергии, та же цена |
| Phase 3 / v2.5 (автономия) | **SG2002 (Milk-V Duo)** | Brain PC + контроллер + AI в одном |
