### Выбор Pico 2W: какой именно брать

Официальный Raspberry Pi Pico 2W имеет **micro-USB**. На Pindodo/AliExpress есть клоны с **USB-C** — предпочтительнее для разработки.

Критерии выбора:
- **USB-C** разъём (удобнее для ежедневной работы)
- **С распаянными пинами** (with headers) — иначе нужна пайка
- **Wi-Fi версия** — убедиться что это именно W (RP2350 + CYW43439)
- Запрос на Pindodo: `RP2350 Pico 2W Type-C headers`

### Обоснование Pico 2W (единственный контроллер)

- Потребление ~20 mA vs ~160 mA у ESP32 — 8× экономия энергии
- Размер 51×21 mm — компактнее ESP32 DevKit (55×28 mm)
- zenoh-pico официально поддерживает RP2350 с января 2025
- Цена ~$7 — нет смысла тратить итерацию на ESP32
- Прямой путь: Webots (Phase 1) → Pico 2W (Phase 2)

## Схема питания

### Шины

| Шина              | Напряжение | Потребители           | Ток (макс.) |
| ----------------- | ---------- | --------------------- | ----------- |
| Серво ноги        | 6V         | GDW DS041MG ×11       | ~3.3A       |
| Серво руки/голова | 5V         | MG90S ×9              | ~1.8A       |
| Логика            | 3.3V       | Pico 2W, PCA9685, IMU | ~0.1A       |

Источник → DC-DC step-down ×3 → три независимых шины.

### Фаза A — розетка (разработка, без батареи)

```
7.4V DC адаптер (≥5A)
        │
   общая шина 7.4V
   ┌────┼────┐
   ↓    ↓    ↓
 6V   5V   3.3V
DC-DC DC-DC DC-DC
 GDW  MG90S Pico
```

Нужен: **DC адаптер 7.4–8V, 5A+** с разъёмом 5.5×2.1mm.
Pico 2W питается через VSYS пин (1.8–5.5V после внутреннего регулятора) — подключать от шины 3.3V или 5V DC-DC, **не** напрямую 7.4V.

### Фаза B — батарея (автономная работа)

```
Li-Po 2S 7.4V (8.4V заряженный)
        │
  [тумблер питания]
        │
   общая шина
   ┌────┼────┐
   ↓    ↓    ↓
 6V   5V   3.3V
DC-DC DC-DC DC-DC
```

Замена: отключить DC адаптер, подключить батарею на тот же вход DC-DC. Схема не меняется.

### Компоненты питания

| Компонент                        | Зачем                          | Фаза   |
| -------------------------------- | ------------------------------ | ------ |
| DC адаптер 7.4–8V 5A (5.5×2.1)  | Питание от розетки             | A      |
| DC-DC step-down ×3               | Шины 6V / 5V / 3.3V           | A + B  |
| Li-Po 2S 7.4V 1200mAh (JST/XT30) | Автономная батарея            | B      |
| Зарядник 2S LiPo (ISDT Q6 nano) | Зарядка батареи                | B      |
| Тумблер питания                  | Вкл/выкл без разъёма          | B      |
| Индикатор напряжения (опц.)      | Контроль заряда батареи        | B      |

**Старт без батареи:** заказать только DC адаптер + DC-DC ×3. Батарейный комплект — позже.
